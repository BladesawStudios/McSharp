# McSharp

A C# library for decoding Nintendo's MeshCodec - the compression format used by `.bfres.mc`
model files and `.chunk` terrain files in *The Legend of Zelda: Tears of the Kingdom*.

[MeshCodec](https://github.com/dt-12345/MeshCodec) - Original C++ Impl
[ZstdSharp.Port](https://github.com/oleg-st/ZstdSharp) - ZSTD Library
